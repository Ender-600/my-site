# Creator mark

The open curve is the approved “Creator 续笔” design for Boyu Liu's portfolio.
Its silhouette was traced from the selected artwork and normalized to a 128 × 128
SVG canvas, preserving its variable stroke weight, rounded terminals, and open
lower-right corner. The website uses forest green (`#233a30`) and warm ivory
(`#f5f3ec`).

- `creator-mark.svg`: transparent vector mark used beside the name in the header.
- `app/icon.svg`: the same mark on an ivory tile for modern browser tabs.
- `app/favicon.ico`: 16, 32, 48, and 64 pixel versions for browser compatibility.
- `app/apple-icon.png`: opaque 180 × 180 icon for Apple home-screen bookmarks.

The App Router discovers the icon files automatically. Keep their silhouette in
sync with this source mark when changing the branding.
